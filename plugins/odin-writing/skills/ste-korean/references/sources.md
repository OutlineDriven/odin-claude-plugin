# STE Korean: 출처와 적용 범위

확인일: 2026-09-05.

## 확인한 공식 자료

[ASD-STE100 공식 홈페이지](https://www.asd-ste100.org/)는
현재 판을 Issue 9, 발행일을 2025-01-15로 표시한다.
표준은 영어 기술문서를 위한 것이며 ASD가 소유한다.

[공식 소개](https://www.asd-ste100.org/about_STE.html)는
작성 규칙, 통제 사전, 분야별 기술 용어라는 구성을 설명한다.

[공식 FAQ](https://www.asd-ste100.org/STE_faq.html)는
절차문과 설명문, 용어의 의미와 품사, 조건의 위치,
행위 주체를 모르는 설명문의 피동 표현 등을 설명한다.

정식 표준은 [공식 배포 안내](https://www.asd-ste100.org/STE_downloads.html)에서 확인한다.
이 패키지는 공식 홈페이지·소개·FAQ를 확인한 범위에 근거한다.
표준 전문 전체에 대한 조항별 대조를 완료한 문서가 아니다.

## 원칙과 구현의 구분

공개 설명에서 참고한 개념은 통제된 용어, 절차와 설명의 구분,
행동 전에 제시하는 조건, 직접적인 지시, 알려지지 않은 주체의 설명이다.

이 패키지에서는 이를 문서 단위 용어 목록, 한국어 명령형과 역할 표기,
조건절의 적용 범위 확인, 주체를 지어내지 않는 규칙으로 구현했다.
전체 표준의 대응표를 제공하는 것은 아니다.
`KS-` 번호, 한국어 문장 패턴, 파괴적 작업의 보류 기준, 보호 문자열 처리,
동시성 보존 검사, 평가 사례는 이 패키지에서 별도로 설계한 것이다.

## 그대로 옮기지 않은 것

영어 승인 단어 목록과 품사 제한을 한국어 사전으로 복제하지 않는다.
영어 단어 수와 한국어 어절 수를 같은 단위로 간주하지 않는다.
영어의 관사, 대문자, 동사 형태, 명사 연쇄 제한을 한국어 형태에 자동 대응시키지 않는다.
한국어의 조사와 어미, 명사형은 실제 뜻과 문장 기능을 기준으로 다룬다.

문서 전체에서 모든 일상 어휘를 통제하는 완결된 한국어 언어 표준도 아니다.
기술 용어와 문장 구조의 통제를 제공하는 실용적인 작성 프로필이다.

## 적합성과 승인에 관한 경계

이 결과를 `공식 한국어 STE`, `ASD 인증`, `ASD-STE100 준수 완료`라고 표시하지 않는다.
내부 검토 통과는 기술적 안전성이나 규제상 적합성의 보증이 아니다.
ASD 로고, 공식 사전, 표준 전문을 패키지에 포함하지 않는다.
원래 표준과 상표의 권리는 권리자에게 있다.

## Agent Skills 형식

[Agent Skills Specification](https://agentskills.io/specification)을 참고했다.
필수 메타데이터는 `name`과 `description`이며, 추가 정보는 `metadata` 안에 둔다.
특정 에이전트의 전용 실행 필드나 도구 권한을 선언하지 않는다.
