# Docs

This directory holds the repository guides and specifications: guides that teach you to use the skills, and specs that govern changes to the tree.

| Document | Read it when |
|---|---|
| [guides/getting-started.md](guides/getting-started.md) | You want to install two plugins and run your first skill. |
| [guides/using-skills.md](guides/using-skills.md) | You want to invoke, stack, and choose between skills. |
| [guides/workflows.md](guides/workflows.md) | You want chains of skills that real sessions proved out. |
| [specs/skill-index.md](specs/skill-index.md) | You want to search every skill by its trigger sentence. |
| [specs/skill-lifecycle.md](specs/skill-lifecycle.md) | You want to add, rename, merge, or retire a skill. |
| [specs/distribution-surfaces.md](specs/distribution-surfaces.md) | You want to know what each harness supports. |
| [specs/gates.md](specs/gates.md) | You want to run a gate or read a gate failure. |
| [specs/install-proof.md](specs/install-proof.md) | You want the recorded runs behind the README commands. |
| [specs/voice.md](specs/voice.md) | You want the prose rules your markdown must pass. |
| [solutions/integration-issues/](solutions/integration-issues/) | You hit a failure where this tree meets another system. |

The three guides and the skill index serve you as a skill user. The rest serve you as a repository contributor.
