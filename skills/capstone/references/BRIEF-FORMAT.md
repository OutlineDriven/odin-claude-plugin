# Brief format

## Template

```md
# Capstone: {slug}

## Done when

- {observable condition a reviewer can test without asking the learner}

## Milestones

1. {milestone} — concepts: {comma-separated}
2. {milestone} — concepts: {comma-separated}

## Concepts exercised

| Concept | Shows as |
|---|---|
| {concept} | {behaviour in the artifact that counts as exercised} |

## Out

- {artifact path or URL}
```

## Rules

- "Understand X" is not a done test. Send an exercise back to `drill`.
- Fill the table's `Shows as` column with behaviour observable in the artifact, not intent.

Review the finished work against the Done when and the Concepts exercised, item by item. Name what is not cleared and hand it to `drill`.
